十、手机适配一定用 dvh

这个项目是 H5，千万别整个页面写死 height: 100vh。

现在手机浏览器有：

Safari 地址栏
微信顶部栏
底部 Home Bar
Android 浏览器动态地址栏

建议：

min-height: 100dvh;


而不是：

height: 100vh;


底部还可以：

padding-bottom: calc(
    20px + env(safe-area-inset-bottom)
);


这样 iPhone 刘海屏 / Home Indicator 会舒服很多。

十一、如果要做出“高级感”，光效最好动态一点

例如背景光缓慢漂移：

.light-orange {
    animation:
        moveOrange 12s ease-in-out infinite alternate;
}

@keyframes moveOrange {

    from {
        transform: translate(0, 0) scale(1);
    }
    
    to {
        transform: translate(-50px, 40px) scale(1.15);
    }

}


紫色：

.light-purple {
    animation:
        movePurple 16s ease-in-out infinite alternate;
}

@keyframes movePurple {

    from {
        transform: translate(0, 0);
    }
    
    to {
        transform: translate(70px, -50px);
    }

}


注意一定要慢。

不要：

animation: 1s infinite;


那会变成廉价的“霓虹灯网页”。

应该：

8s
12s
16s
20s


这种级别。
