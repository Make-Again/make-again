# **一个帮助人接受离别，并重新学习如何带着这段关系继续生活的 AI 陪伴产品**

- **背景**：
  -  半年前，Venus 的外公离世。外公去世后，妈妈很长时间无法从悲伤中走出来。她会因为一件熟悉的物品想起父亲，会突然陷入回忆，也会害怕那些关于他的记忆慢慢消失。与此同时，团队成员 Ruoxi 也有类似的经历。外婆离世后，她看到妈妈经常吃不下饭，一个人默默的流泪。我们开始意识到：离别并不会随着时间自动结束。一个人失去的，也不仅仅是另一个人。

  -  因此我们想做一款帮助大家接受离别的产品，不仅帮到我们身边的妈妈们，还能帮到其他经历了至亲离世的伤痛又或是分手失恋的人，**不是帮助用户“忘记”，而是帮助用户重新学习如何带着这段关系继续生活，比“帮助人走出创伤”更好**
- **用户痛点：**
  -  分手、亲人离世、宠物离世，表面上都是失去、没有重新振作起来的勇气，但用户经历的可能完全不同

  - **分手：**用户失去的不只是一个人，而是：每天聊天的习惯、一个情绪出口，以及曾经一起想象过的未来。
    1.   用户交往对象的痛点：你是不是真的忘掉了前任？我如何放心地跟你在一起。
  - **亲人离世：**用户失去的可能更复杂：再也无法见面的可能、那些还没来得及说出口的话，以及害怕记忆逐渐消失的恐惧。 
    1.   一个很强的情绪可能是：**“我不想忘记他，但我也不能永远活在失去他的那一天。”**
  - **宠物离世：**很多人会经历一种很特殊的痛苦：我知道别人可能觉得这只是一只宠物，但对我来说，它是我的家人。（同时用户可能有大量：照片、视频、日常记录。非常适合 AI生成回忆纪念）

真正需要解决的问题可能是：**如何从“被过去困住”，变成“带着过去继续往前走”。**

- **具体功能****：**
  - 首次注册登录后，列一个 question list （包含心理测评）选一个问题让ai跟用户对话，再补充追问问题构成个人画像和忘不掉的对象的画像——梳理事情的原因、情绪波动/困惑点
  - 根据这些画像生成反馈报告，用户可以补充叙述内容——ai总结，理清目标（是忘记还是带着记忆走下去）并且和客户一起确认疗愈plan 
  - 每天可选择再聊聊忘不掉的对象，然后根据时间/用户在做什么触发情况（白天去做事情；晚上别熬夜）eg：你以前周六晚上总是和他打电话。这个星期，我们换一种方式度过这个时间。——软引导用户去不要内耗
  - 定期生成报告——将情绪方面数字化
  - 心情每日记录，不只是普通的开心生气等表情包，而是更细节的：“你这周最难过的时间，通常出现在晚上。”、“你最近已经三次提到同一个地方。”——发现用户自己看不到的变化
  - 真实用户的交互树洞：匹配到类似经历的用户，写一些帮助别人的话，痛苦的人写一封信类似于漂流瓶（痛苦情绪下喜欢手打和输入语音），隔段时间收到已经走出来的人的回信。——适合社媒宣传
  - 针对失恋：跟对方有关的物件抠图数字化并最后真正忘掉了后有灰飞烟灭的效果；最后结束时有以对方口吻的小作文 
  - 针对亲人：用户上传含亲人声音的素材生成鼓励录音——适合社媒宣传（比如 Untangle Grief 就允许用户通过记忆、故事、声音等信息创建一个“受思念之人启发”的对话形象）
  - 针对宠物：用户上传含宠物长相的素材生成 ai 视频（宠物领域也已经出现 SoulBridge 这样的 AI 纪念与互动产品。）
  - 更仿人声、ai 味淡的系统声音
  - 更精美的 ui 交互
- **如何帮助用户验证是否真正走出来：**
  -  模拟一个来自前任的电话，看用户是否真正有勇气释怀、接电话
- **slogan：**
  - 我们不帮助你忘记谁，而是陪你慢慢学会，在失去之后继续生活。
- **创新点：**
  - 用户树洞
  - 不定时地报告
  - 真人现实疗愈般的体验 ai+现实（硬件rokid）
-  **社媒运营：**情感小视频/伤感文案、亲人鼓励录音、交互树洞
